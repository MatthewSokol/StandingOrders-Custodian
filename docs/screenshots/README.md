# Screenshots

The README and every addon page show these. Take them on a test character, then check each image before committing:

- every player, character, guild and realm name is blurred, blacked out or replaced with a made-up one (nameplates, unit
  frames, chat, tooltips, the bag and bank frames' titles, lists);
- no chat lines from other players;
- no account or real names anywhere (the window title, addon lists, file paths).
